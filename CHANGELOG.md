# Changelog

## v4 — AniList hybride

- Réintégration d’AniList pour les posters.
- Poster local prioritaire, AniList en deuxième choix, SVG en secours.
- Cache AniList dans `localStorage`.
- Requêtes GraphQL groupées pour limiter la charge.
- Bouton de rafraîchissement des affiches manquantes.
- Script Node sans dépendance pour télécharger les posters dans le repo.
- Export PNG protégé contre les problèmes CORS.
- Conservation des deux modes Rapide et AniShelf.
